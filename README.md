# 本子工坊 2 · 静态资源库

这里保存本子工坊 2 的画风选择页、压缩预览图、角色与作品图集、字体和提示词库。

- `index.html`：GitHub Pages 画风选择入口
- `artists.js`：画师名称及图片索引
- `styles/`：压缩后的 WebP 预览图
- `anime-characters.js`：角色与作品索引
- `anime-atlas-v2/`：角色预览图集
- `anime-work-atlas/`：作品封面图集
- `prompt-library.js`：分镜和外观提示词库
- `fonts/`：界面字体
- `asset-manifest.json`：供卡片检查资源路径的清单
- `.nojekyll`：关闭 Jekyll 处理

打开页面即可选择、收藏、搜索画风，并复制当前画师串。

卡片使用以下静态资源前缀：

`https://cdn.jsdelivr.net/gh/UGentertainment/bzgf2@main/`
